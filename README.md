# LessonLab Website Mockup

A standalone, responsive website concept for Lesson Lab East London, a tutoring and learning centre in Vincent.

## Preview locally

Open `index.html` in any modern web browser. No build step or external dependencies are required.

## Project scope

- Orange-led, colourful visual direction
- Primary and high-school learning support
- CAPS-aligned positioning
- Responsive desktop and mobile layouts
- Interactive enquiry modal, forms, and FAQ

> Concept mockup only — not the current official Lesson Lab website.
